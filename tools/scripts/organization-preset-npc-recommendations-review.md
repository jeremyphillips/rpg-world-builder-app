# Preset NPC role recommendations

Authored directly in the eight v1 NPC roles. Regenerated by
`node tools/scripts/build-organization-preset-npc-recommendations.mjs` and
`node tools/scripts/generate-organization-membership-title-data.mjs`.

There is no 22-id translation layer. Dropped legacy roles (performer, healer,
sailor, administrator, civic leader, and the martial rank ladder) are expressed
with a v1 role plus title refinements when the mechanical seed differs from that
role's own class preferences.

## Refinements

- `classPreferenceOverrideSlugs` replaces the template class list.
- `skillPreferenceSlugs` and `toolPreferenceSlugs` are prepended. They do not add slots.
- `level` stays on the title. Templates carry no level.

## Examples

| Preset:title                 | Recommendation                                 |
| ---------------------------- | ---------------------------------------------- |
| `army:captain`               | guard · 6, class override fighter + paladin    |
| `shipping_company:captain`   | guard · 6                                      |
| `craft_guild:master_artisan` | artisan · 5                                    |
| `thieves_guild:guildmaster`  | criminal · 9                                   |
| `mage_college:rector`        | scholar · 10, class override wizard + sorcerer |

Artisan titles that name a trade prepend that trade's tool (`brewers-supplies`,
`carpenters-tools`). Organization defaults live in
`preset-member-npc-templates.ts` and apply only when a title has no recommendation.
