# SRD 5.2.1 lair and legendary audit

Sources: Open5e v2 `document__key=srd-2024` (331 creatures) and the SRD 5.2.1 PDF (InDesign export dated 2025-04-29). Open5e does not carry in-lair XP, legendary use counts, or proficiency bonus.

## Corpus summary

- **Legendary actions:** 30 creatures; pool size is always 3; 27 print `(4 in Lair)`; Unicorn, Solar, and Tarrasque have no lair pool.
- **Legendary Resistance:** 32 creatures; lair rows are exactly +1 (15 at 3/4 per day, 12 at 4/5); plain rows include Balor 3/Day, Pit Fiend and Solar 4/Day, Tarrasque 6/Day.
- **In-lair XP:** 27 creatures; every published value equals the XP of the next challenge rating in table order. No counterexamples.
- **CR 30:** Tarrasque has no in-lair XP; suggested XP at CR 30 stays unavailable. Rejected extrapolations: 175,000, 170,000, 178,000.

## Data-quality exceptions

- Archmage CR 12 prints XP 8,000; table and Open5e use 8,400.
- CR 0 awards 0 XP on some creatures; table text is "0 or 10".

## Advisory evidence

Low CR legendary actions: Unicorn (CR 5) only. Standard legendary pool: 3 uses. In-lair override: +1 when present. Legendary Resistance daily uses in SRD: 3, 4, or 6.
